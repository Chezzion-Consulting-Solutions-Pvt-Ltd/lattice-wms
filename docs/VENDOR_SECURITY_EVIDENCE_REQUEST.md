# Vendor Security Evidence Request

Use this request when collecting third-party security evidence for Lattice vendors, hosting providers, managed services, implementation partners, or other suppliers that support the application, infrastructure, data processing, or operational controls.

## Security Assessment Checklist

The vendor must complete all questions in the attached Security Assessment Checklist spreadsheet.

- Answer every question.
- Mark questions that do not apply as `Not Applicable`.
- Provide comments and evidence links where requested.
- Identify any compensating controls for partial or unavailable controls.

## SOC 2 Type II Report

Request the latest SOC 2 Type II report covering:

- Application services.
- Infrastructure and hosting environments.
- Supporting services.
- Security, availability, confidentiality, privacy, and processing-integrity controls where applicable.
- Relevant subservice organizations and complementary user entity controls.

If the SOC 2 Type II evaluation is in progress or the report period has expired, request a bridge letter confirming continued control operation for the interim period.

## Data Privacy And Protection Compliance

Request evidence of compliance with applicable data privacy and protection regulations for every country or region where data is collected, stored, processed, accessed, or transferred.

Evidence may include:

- Privacy policy and data processing addendum.
- GDPR, DPDP, CCPA/CPRA, or other applicable compliance statements.
- Data residency and cross-border transfer documentation.
- Subprocessor list.
- Data retention and deletion procedures.
- Personal data breach notification procedure.

## ISO Certification

Request valid ISO certificate copies, where applicable, such as:

- ISO/IEC 27001.
- ISO/IEC 27017.
- ISO/IEC 27018.
- ISO/IEC 27701.
- Other applicable security, privacy, or continuity certifications.

Also request the Statement of Applicability with certification scope and coverage details.

## Vulnerability Assessment And Penetration Testing

Request the latest reports with executive summary, findings, remediation status, and closure evidence.

Required reports:

- Latest application vulnerability assessment.
- Latest infrastructure vulnerability assessment.
- Latest web application penetration test.
- Latest LLM security assessment, if AI or LLM features are used or supported.
- Latest mobile application penetration test for iOS and Android, if mobile applications are in scope.

For each finding, request:

- Severity rating.
- Affected asset or component.
- Business impact.
- Remediation owner.
- Target remediation date.
- Closure or retest evidence.

## Business Continuity And Disaster Recovery

Request the latest Disaster Recovery drill report, including:

- Test scope.
- Test date.
- Recovery time objective validation.
- Recovery point objective validation.
- Results.
- Observations.
- Identified gaps.
- Remediation and closure status.

Request the latest backup restoration test report, including:

- Restoration scope.
- Success criteria.
- Restoration validation results.
- Issues identified.
- Remediation actions.
- Closure evidence.

## Review And Acceptance

Lattice security review must record:

- Vendor name.
- Services in scope.
- Data categories handled.
- Countries or regions involved.
- Evidence received.
- Open risks.
- Accepted risks.
- Required remediation.
- Review owner.
- Review date.
- Next review date.
