# Tenant Console

The Tenant Console is the tenant-facing administration surface for warehouse configuration. It is separate from the Owner Console and uses server-resolved tenant context from active verified tenant domains, authenticated users, active tenant memberships, tenant roles, and permissions.

Implemented routes include dashboard, plants, warehouses, storage types, zones, sections, bays, hierarchy, warehouse configuration, tenant users, tenant roles, warehouse assignments, profile, security, and settings.

Operational workflows are intentionally later: KnightVizion, inbound, receiving, ASN, GR, putaway, inventory execution, outbound, shipping, PGI, RF, and voice.
